# AITradra Roadmap

This roadmap is designed to help users, contributors and investors understand what AITradra is building next.

AITradra is a market-intelligence and trading-engineering platform. It does not guarantee returns or prediction accuracy.

## v0.1 — Public alpha foundation ✅

Current foundation:

- Customer-first market intelligence UI
- Multi-agent research pipeline
- Stock, ETF, crypto and India equity data collection
- RSS/news evidence collection
- Social-data provenance handling
- Prediction, confidence and risk summaries
- Practice trading with fees and slippage
- Customer API/data connection workflow
- Manual Hyperliquid integration path
- Fail-closed live trading model
- Safety CI and live-system smoke verification

## v0.2 — Contributor and integration layer

Priority goals:

- Improve one-command local setup
- Add Playwright end-to-end browser tests
- Add better onboarding walkthrough for non-developers
- Add more data adapters
- Add more broker adapters
- Add contributor-friendly plugin boundaries
- Improve mobile responsiveness
- Add prediction calibration dashboard
- Add release artifacts and demo video

Suggested issues:

- Add Alpaca broker adapter
- Add Binance paper broker adapter
- Add Interactive Brokers research-only adapter
- Add Polygon.io market-data adapter
- Add SEC/earnings transcript ingestion
- Add NSE India symbol search improvements
- Add UI walkthrough for first-time users
- Add exportable research report PDF

## v0.3 — Intelligence and evaluation layer

Priority goals:

- Prediction accuracy tracking by ticker and horizon
- Signal calibration curves
- Agent disagreement/consensus dashboard
- Strategy validation dashboard
- Backtesting UI for customer-selected strategies
- Portfolio risk attribution
- Earnings-event impact analysis
- News-source reliability scoring
- More transparent confidence scoring

## v0.4 — Platform layer

Priority goals:

- Hosted deployment path
- Multi-user accounts
- Team workspaces
- API access for research outputs
- Webhook alerts
- Broker plugin SDK
- Data-source plugin SDK
- Admin risk controls
- Audit log viewer

## v1.0 — Stable market intelligence platform

Goals before v1.0:

- Documented security model
- Stable plugin interfaces
- Production deployment guide
- Strong E2E test coverage
- Prediction evaluation transparency
- Multiple verified data-source adapters
- Multiple verified broker adapters
- Clear legal disclaimers and customer onboarding
- No real-money pathway enabled by default

## What contributors can help with now

If you want to contribute, focus on:

1. Better setup and docs
2. More realistic paper trading
3. Better market/news data coverage
4. Prediction evaluation
5. Risk dashboards
6. Broker adapters
7. UI polish
8. Automated tests

## What will not be accepted

- Guaranteed-profit claims
- Hidden live-trading shortcuts
- Auto-enabled real-money trading
- Hard-coded API keys
- Fake/stale data presented as live
- Model outputs bypassing deterministic risk gates
