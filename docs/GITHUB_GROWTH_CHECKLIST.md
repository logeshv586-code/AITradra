# GitHub Growth Checklist for AITradra

These settings must be applied from the GitHub repository UI because they are repository settings, not normal files.

## About section

Set the repository description to:

> Open-source multi-agent AI platform for market intelligence, explainable stock research, prediction tracking, risk analysis and safety-gated trading.

Set homepage to the deployed demo or product landing page when available.

## Repository hygiene

- Keep README accurate and conservative.
- Pin the best demo video/link.
- Keep issues labeled.
- Convert roadmap items into issues.
- Close stale or duplicate issues politely.
- Keep releases meaningful.

## Star-growth target

Suggested staged targets:

| Stage | Goal | Signal |
|---|---:|---|
| Launch | 25 stars | People understand the project |
| Community | 100 stars | Developers are curious |
| Contributor | 250 stars | Outside PRs begin |
| Investor-ready | 500+ stars + users | Project has public technical traction |

Stars alone are not enough. Track active users, repeat usage, analyses generated, paper trades, external contributors and pilot conversations.
