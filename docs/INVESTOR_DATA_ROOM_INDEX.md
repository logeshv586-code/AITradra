# Investor Data Room Index

This is a suggested structure for an AITradra investor/data-room folder. Keep private financial and user data outside the public GitHub repository.

## 1. Company

- Company overview
- Founder/team bios
- Registration documents when available
- Cap table when available

## 2. Product

- Product screenshots
- Demo video
- Demo script
- User flows
- Roadmap
- Architecture diagrams

## 3. Technology

- System architecture
- Safety model
- Data-source model
- Broker integration model
- AI-agent architecture
- Testing and CI evidence

## 4. Traction

Track monthly:

- GitHub stars
- forks
- contributors
- issues/PR activity
- registered users
- weekly active users
- research sessions
- paper trades
- connected data APIs
- retention
- user feedback
- pilot conversations

## 5. Prediction evaluation

Track transparently:

- total predictions
- prediction horizon
- win/loss definition
- confidence calibration
- benchmark comparison
- risk-adjusted metrics
- blocked trades
- model disagreement

Do not cherry-pick only successful predictions.

## 6. Business

- Pricing experiments
- Target customer segments
- Pilot pipeline
- Sales notes
- Competitor comparison
- Go-to-market plan

## 7. Legal and risk

- Financial disclaimers
- Terms draft
- Privacy policy draft
- Security policy
- Live-trading risk controls
- Regulatory research notes

## 8. Fundraise

- Investor deck
- One-pager
- Fundraising target
- Use of funds
- Hiring plan
- 12-month milestones

## Public vs private

Public GitHub should contain:

- README
- roadmap
- architecture docs
- contribution docs
- open issues
- release notes
- conservative public claims

Private data room should contain:

- customer data
- financials
- investor conversations
- credentials
- legal documents
- sensitive strategy results
